3 ОПИС ВИКОНАНОЇ РОБОТИ

3.1 Загальні відомості про шаблони (патерни) проєктування

Патерни проектування є часто використовуваними способами реалізації певного типу взаємодії між класами та створення їх об'єктів за певними правилами. У книзі «Патерни об'єктно-орієнтованого проектування» її автори (так звані Gang of Four – Гамма Е., Хелм Р., Джонсон Р., Вліссідес Д.) виділили та описали найбільш поширені патерни, зазначаючи їх структуру, мету застосування та поради щодо їх використання. Патерни GoF діляться на три великі групи: поведінкові, структурні та породжувальні. До поведінкових відносяться патерни, що допомогають реалізувати взаємодію між об'єктами програми найбільш ефективним чином. Структурні патерни вирішують проблему компонування об'єктів та спрощення інтерфейсів. Породжувальні патерни знаходять використання при потребі контролювати створення та ініціалізацію об'єктів. Ця група патернів в першу чергу орієнтована та описана для мов, що мають гарну підтримку об'єктно-орієнтованої парадигми, проте варіанти їх реалізації існують і в інших популярних парадигмах.

3.2 Опис обраного патерна

Назва патерна: Ітератор.
Тип шаблона (патерна): поведінковий.
Основне призначення: необхідність зручної ітерації по елементам об'єкта і при цьому не руйнувати інкапсуляцію та гарантії, що вона надає.
Передумови застосування: є колекція або інша складна структура даних (наприклад, реалізація патерну Композит або дерево, що обходиться за певними алгоритмами) і необхідно реалізувати можливість послідовного з боку клієнта обходу даного об'єкту таким чином, що клієнтському коду не потрібно знати про особливості внутрішньої організації структури даних.
Переваги: може спростити використання класів, що призначені для зберігання даних і мають складну структуру їх зберігання (наприклад, ієрархічну), різні ітератори можуть реалізовувати різні алгоритми обходу структури.
Недоліки: може додати непотрібну складність, якщо клієнтський код може використати звичайний цикл.

3.3 Структура шаблона (патерна)

Опис структурних частин:
Патерн Ітератор складається з чотирьох основних учасників.
IIterator<T> — абстрактний інтерфейс ітератора. Оголошує операції для послідовного обходу елементів. Наприклад, Next() (отримання наступного елемента) та Reset() (скидання позиції до початку).
IIterableCollection<T> — абстрактний інтерфейс агрегату (колекції). Оголошує фабричний метод CreateIterator(), що повертає об'єкт відповідного ітератора.
Iterator — конкретний ітератор. Реалізує інтерфейс IIterator<T> та зберігає поточну позицію у послідовності. Містить логіку, що безпосередньо повертає наступний елемент агрегату.
IterableCollection — конкретний агрегат. Реалізує інтерфейс IIterableCollection<T >, зазвичай зберігає елементи колекції або складної структури та створює екземпляр Iterator через метод CreateIterator().

Опис взаємодії об'єктів
Клієнтський код створює об'єкт IterableCollection, передаючи вхідні дані. Викликаючи метод CreateIterator(), клієнт отримує об'єкт LexerIterator, що знає лише про рядок та поточну позицію в ньому. Клієнт циклічно викликає MoveNext(), не маючи жодної залежності від внутрішніх деталей лексичного аналізу. Метод Reset() дозволяє повторно обійти ті самі токени без створення нового ітератора.

3.4 Реалізація шаблона (патерна)

У цій реалізації патерн Iterator використано для послідовного обходу вхідного тексту та перетворення його на набір токенів. Ітератор інкапсулює логіку розбору рядка, а клієнтський код працює лише з абстракцією, не знаючи деталей лексичного аналізу. 
1. Створення базових інтерфейсів
Спочатку визначено два узагальнені інтерфейси:
IIterator<T> – описує поведінку ітератора.
Він містить метод MoveNext(), який переходить до наступного елемента, властивість Current для отримання поточного елемента та метод Reset() для скидання стану.
IIterableCollection<T> – описує колекцію, яка може створювати ітератор.
Її єдиний метод CreateIterator() повертає об’єкт типу IIterator<T>.
Таке розділення відповідає ідеї патерну Iterator: колекція не розкриває свою внутрішню структуру, а надає спосіб послідовного обходу елементів.
2. Реалізація конкретних класів
Для демонстрації патерну створено клас Token, який представляє один лексемний елемент. Він зберігає два значення: Text – текст токена, та Type – його тип, наприклад integer, keyword, operator, string, identifier або whitespace.
Основна логіка зосереджена в класі LexerIterator, який реалізує IIterator<Token>.
Цей клас зберігає вхідний рядок у вигляді масиву символів, а також службові поля для поточної позиції, поточного токена та стану обходу.
Метод MoveNext() аналізує символи починаючи з поточної позиції та визначає, який саме токен потрібно зчитати. Для цього використовується розгалуження за першим символом:
•	якщо символ є оператором, викликається LexOp(); 
•	якщо це цифра, викликається LexInteger(); 
•	якщо це лапка, викликається LexStr(); 
•	якщо це пробільний символ, викликається LexWhitespace(); 
•	в усіх інших випадках виконується перевірка на логічні значення, ключові слова або ідентифікатори через LexBooleanIdentifierKeyword(). 
Кожен окремий метод відповідає за зчитування конкретного типу токена:
•	LexOp() створює токен-оператор; 
•	LexInteger() зчитує послідовність цифр; 
•	LexStr() зчитує рядковий літерал у лапках; 
•	LexWhitespace() зчитує послідовність пробілів, табуляцій або переходів на новий рядок; 
•	LexBooleans() розпізнає true і false; 
•	LexKeywords() розпізнає службові слова return, if, else, for, while, func, break; 
•	LexIdentifiers() зчитує ідентифікатори, які можуть містити літери, цифри, символ _ і $. 
Таким чином, LexerIterator не просто обходить колекцію, а виконує прикладну логіку лексичного аналізу.
Клас LexingCollection реалізує IIterableCollection<Token> і зберігає вхідний буфер. Його завдання просте: створити новий екземпляр LexerIterator для переданого тексту. Це дозволяє відокремити саму колекцію від механізму її обходу.
3. Демонстрація використання
У методі Main() створюється вхідний рядок:
func calculate(int x)\nreturn x + 2
Далі цей рядок передається до LexingCollection, після чого викликається CreateIterator(). Отриманий ітератор використовується в допоміжному методі ToArray(), де цикл while (lexer.MoveNext()) послідовно читає всі токени та додає їх у список.
Після цього токени виводяться в консоль у форматі:
Text - Type

2 using System.Text;
3
4 namespace Solution;
5
6 public class Token
7 {
8     public string Text { get; }
9     public string Type { get; }
10
11     public Token(string text, string type)
12     {
13         Text = text;
14         Type = type;
15     }
16 }
17
18 public interface IIterator<T>
19 {
20     bool MoveNext();
21     T Current { get; }
22     void Reset();
23 }
24
25 public interface IIterableCollection<T>
26 {
27     IIterator<T> CreateIterator();
28 }
29
30 public class LexerIterator : IIterator<Token>
31 {
32     private const string IntegerCode = "integer";
33     private const string BooleanCode = "boolean";
34     private const string OperatorCode = "operator";
35     private const string StringCode = "string";
36     private const string KeywordCode = "keyword";
37     private const string WhitespaceCode = "whitespace";
38     private const string IdentifierCode = "identifier";
39     private const string True = "true";
40     private const string False = "false";
41     private const string Return = "return";
42     private const string If = "if";
43     private const string Else = "else";
44     private const string For = "for";
45     private const string While = "while";
46     private const string Func = "func";
47     private const string Break = "break";
48
49     private readonly char[] _str;
50     private int _currIndex;
51     private Token _current;
52     private readonly int _len;
53     private bool _hasNotMovedNext;
54
55     public LexerIterator(string buffer)
56     {
57         if (buffer is null)
58         {
59             buffer = "";
60         }
61         _str = new char[buffer.Length];
62         _len = buffer.Length;
63         for (var i = 0; i < buffer.Length; ++i)
64         {
65             _str[i] = buffer[i];
66         }
67     }
68
69     public Token Current
70     {
71         get
72         {
73             if (_hasNotMovedNext)
74             {
75                 throw new InvalidOperationException("No current token available.");
76             }
77             return _current;
78         }
79     }
80
81     public void Reset()
82     {
83         _currIndex = 0;
84     }
85
86     public bool MoveNext()
87     {
88         if (_currIndex >= _len)
89         {
90             _hasNotMovedNext = true;
91
92             return false;
93         }
94
95         var res = false;
96         switch (_str[_currIndex])
97         {
98             case '+' or '-' or '*' or '/' or '%' or '(' or ')' or '=':
99                 {
100                     res = LexOp();
101                     break;
102                 }
103             case '0' or '1' or '2' or '3' or '4' or '5' or '6' or '7' or '8' or '9':
104                 {
105                     res = LexInteger();
106                     break;
107                 }
108             case '"':
109                 {
110                     res = LexStr();
111                     break;
112                 }
113             case ' ' or '\t' or '\n':
114                 {
115                     res = LexWhitespace();
116                     break;
117                 }
118             default:
119                 {
120                     res = LexBooleanIdentifierKeyword();
121                     break;
122                 }
123         }
124
125         _hasNotMovedNext = !res;
126
127         return res;
128     }
129
130     private bool LexOp()
131     {
132         _current = new Token(_str[_currIndex++].ToString(), OperatorCode);
133
134         return true;
135     }
136
137     private bool LexInteger()
138     {
139         var sb = new StringBuilder();
140         var i = _currIndex;
141         while (i < _len && _str[i] >= '0' && _str[i] <= '9')
142         {
143             sb.Append(_str[i]);
144             i++;
145         }
146
147         _currIndex = i;
148         _current = new Token(sb.ToString(), IntegerCode);
149
150         return true;
151     }
152
153     private bool LexStr()
154     {
155         var sb = new StringBuilder();
156         sb.Append('"');
157         var i = ++_currIndex;
158         while (i < _len && _str[i] != '"')
159         {
160             sb.Append(_str[i]);
161             i++;
162         }
163
164         if (i < _len && _str[i] == '"')
165         {
166             sb.Append('"');
167             _currIndex = i + 1;
168             _current = new Token(sb.ToString(), StringCode);
169
170             return true;
171         }
172         else
173         {
174             return false;
175         }
176     }
177
178     private bool LexWhitespace()
179     {
180         var sb = new StringBuilder();
181         var i = _currIndex;
182         while (i < _len && (_str[i] == ' ' || _str[i] == '\t' || _str[i] == '\n'))
183         {
184             sb.Append(_str[i]);
185             i++;
186         }
187
188         _currIndex = i;
189         _current = new Token(sb.ToString(), WhitespaceCode);
190
191         return true;
192     }
193
194     private Token LexBooleans()
195     {
196         if (_len - _currIndex >= 4)
197         {
198             var span = new ReadOnlySpan<char>(_str, _currIndex, 4);
199             if (span is True)
200             {
201                 _currIndex += 4;
202
203                 return new Token(True, BooleanCode);
204             }
205         }
206
207         if (_len - _currIndex >= 5)
208         {
209             var span = new ReadOnlySpan<char>(_str, _currIndex, 5);
210             if (span is False)
211             {
212                 _currIndex += 5;
213
214                 return new Token(False, BooleanCode);
215             }
216         }
217
218         return null;
219     }
220
221     private Token LexKeywords()
222     {
223         for (int i = 2; i <= 6; ++i)
224         {
225             if (_len - _currIndex >= i)
226             {
227                 var span = new ReadOnlySpan<char>(_str, _currIndex, i);
228                 if (span is Return or If or Else or For or While or Func or Break)
229                 {

public class LexerIterator : IIterator<Token>
{
    private const string IntegerCode = "integer";
    private const string BooleanCode = "boolean";
    private const string OperatorCode = "operator";
    private const string StringCode = "string";
    private const string KeywordCode = "keyword";
    private const string WhitespaceCode = "whitespace";
    private const string IdentifierCode = "identifier";
    private const string True = "true";
    private const string False = "false";
    private const string Return = "return";
    private const string If = "if";
    private const string Else = "else";
    private const string For = "for";
    private const string While = "while";
    private const string Func = "func";
    private const string Break = "break";

    private readonly char[] _str;
    private int _currIndex;
    private Token _current;
    private readonly int _len;
    private bool _hasNotMovedNext;

    public LexerIterator(string buffer)
    {
        if (buffer is null)
        {
            buffer = "";
        }
        _str = new char[buffer.Length];
        _len = buffer.Length;
        for (var i = 0; i < buffer.Length; ++i)
        {
            _str[i] = buffer[i];
        }
    }

    public Token Current
    {
        get
        {
            if (_hasNotMovedNext)
            {
                throw new InvalidOperationException("No current token available.");
            }
            return _current;
        }
    }

    public void Reset()
    {
        _currIndex = 0;
    }

    public bool MoveNext()
    {
        if (_currIndex >= _len)
        {
            _hasNotMovedNext = true;

            return false;
        }

        var res = false;
        switch (_str[_currIndex])
        {
            case '+' or '-' or '*' or '/' or '%' or '(' or ')' or '=':
                {
                    res = LexOp();
                    break;
                }
            case '0' or '1' or '2' or '3' or '4' or '5' or '6' or '7' or '8' or '9':
                {
                    res = LexInteger();
                    break;
                }
            case '"':
                {
                    res = LexStr();
                    break;
                }
            case ' ' or '\t' or '\n':
                {
                    res = LexWhitespace();
                    break;
                }
            default:
                {
                    res = LexBooleanIdentifierKeyword();
                    break;
                }
        }

        _hasNotMovedNext = !res;

        return res;
    }

    private bool LexOp()
    {
        _current = new Token(_str[_currIndex++].ToString(), OperatorCode);

        return true;
    }

    private bool LexInteger()
    {
        var sb = new StringBuilder();
        var i = _currIndex;
        while (i < _len && _str[i] >= '0' && _str[i] <= '9')
        {
            sb.Append(_str[i]);
            i++;
        }

        _currIndex = i;
        _current = new Token(sb.ToString(), IntegerCode);

        return true;
    }

    private bool LexStr()
    {
        var sb = new StringBuilder();
        sb.Append('"');
        var i = ++_currIndex;
        while (i < _len && _str[i] != '"')
        {
            sb.Append(_str[i]);
            i++;
        }

        if (i < _len && _str[i] == '"')
        {
            sb.Append('"');
            _currIndex = i + 1;
            _current = new Token(sb.ToString(), StringCode);

            return true;
        }
        else
        {
            return false;
        }
    }

    private bool LexWhitespace()
    {
        var sb = new StringBuilder();
        var i = _currIndex;
        while (i < _len && (_str[i] == ' ' || _str[i] == '\t' || _str[i] == '\n'))
        {
            sb.Append(_str[i]);
            i++;
        }

        _currIndex = i;
        _current = new Token(sb.ToString(), WhitespaceCode);

        return true;
    }

    private Token LexBooleans()
    {
        if (_len - _currIndex >= 4)
        {
            var span = new ReadOnlySpan<char>(_str, _currIndex, 4);
            if (span is True)
            {
                _currIndex += 4;

                return new Token(True, BooleanCode);
            }
        }

        if (_len - _currIndex >= 5)
        {
            var span = new ReadOnlySpan<char>(_str, _currIndex, 5);
            if (span is False)
            {
                _currIndex += 5;

                return new Token(False, BooleanCode);
            }
        }

        return null;
    }

    private Token LexKeywords()
    {
        for (int i = 2; i <= 6; ++i)
        {
            if (_len - _currIndex >= i)
            {
                var span = new ReadOnlySpan<char>(_str, _currIndex, i);
                if (span is Return or If or Else or For or While or Func or Break)
                {
                    _currIndex += i;

                    return new Token(span.ToString(), KeywordCode);
                }
            }
        }

        return null;
    }

    private Token LexIdentifiers()
    {
        var sb = new StringBuilder();
        while (_currIndex < _len && !IsStopIdentifierLexing(_str[_currIndex]))
        {
            sb.Append(_str[_currIndex]);
            _currIndex++;
        }

        return new Token(sb.ToString(), IdentifierCode);

        bool IsStopIdentifierLexing(char c)
        {
            var isOp = c == '+' || c == '-' || c == '*' || c == '/' || c == '%' || c == '(' || c == ')' || c == '=';
            var isWhiteSpace = c == ' ' || c == '\n' || c == '\t';
            var isNotAlphaNumericExtended = !(char.IsLetterOrDigit(c) || c == '_' || c == '$');

            return isOp || isWhiteSpace || isNotAlphaNumericExtended;
        }
    }

    bool LexBooleanIdentifierKeyword()
    {
        var token = LexBooleans();
        if (token is not null)
        {
            _current = token;

            return true;
        }

        token = LexKeywords();
        if (token is not null)
        {
            _current = token;

            return true;
        }

        token = LexIdentifiers();
        if (token is not null)
        {
            _current = token;

            return true;
        }

        return false;
    }
